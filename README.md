# Weather App

Python weather application that consumes a real weather API to practice HTTP requests, JSON handling, environment variables and clean project structure.

## Features

- Search weather by city
- Show temperature in Celsius
- Show weather description
- Show humidity
- Interactive terminal menu
- API key protected with environment variables

## Technologies

- Python
- Requests
- Python-dotenv
- OpenWeatherMap API
- Git
- GitHub
